# student-exam-scores-analysis
Statistical analysis of student exam scores using Python, including descriptive statistics, hypothesis testing, and data visualisation to explore patterns in academic performance.
•	Cleaned and explored a student exam score dataset in Python, computing descriptive statistics to summarize performance.
•	Applied statistical hypothesis tests to assess whether differences in scores between student groups were significant based on t-test
•	Created charts and visualizations (histograms, box plots, seaborn pairplot and hue-based comparisons for interactions to communicate patterns in the data and support evidence-based conclusions.
